# Data Analyst Portfolio

SQL portfolio projects focused on turning raw data into clear, decision-ready insights.

## Projects

### 1. Student Performance Analysis

Analyzes 1,000 student exam records to identify performance gaps, at-risk students, and factors associated with stronger outcomes.

**Skills:** PostgreSQL, data validation, aggregations, conditional logic, CTEs, subqueries, and window functions.

[View project](student-performance-analysis/README.md)

### 2. Retail Sales Performance Analysis

Analyzes 9,994 Superstore transaction rows to evaluate revenue, profitability, regional performance, discounts, and product trends.

**Skills:** PostgreSQL, data cleaning, joins, CTEs, date analysis, ranking, running totals, and business recommendations.

[View project](retail-sales-analysis/README.md)
