# Dataset

Download the public Sample Superstore CSV and save it here as `superstore.csv`. A copy of the dataset used for validation is available from this [public analytics dataset location](https://github.com/denindrap23/Excel/blob/main/Sales%20Analytics/dataset/superstore.csv).

The analysis was validated against 9,994 transaction line items covering 2014–2017. The source file is not duplicated here so the original distribution location remains the authoritative source.
