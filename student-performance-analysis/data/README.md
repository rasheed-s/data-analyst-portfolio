# Dataset

Download `StudentsPerformance.csv` from the [Students Performance in Exams Kaggle page](https://www.kaggle.com/datasets/spscientist/students-performance-in-exams) and save it here as `students_performance.csv`.

The analysis was validated against the 1,000-row public dataset. The source file is not duplicated in this repository so its original distribution page remains the authoritative source.
